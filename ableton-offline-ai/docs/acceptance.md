# 受け入れ試験と現時点の限界

## 自動試験で確認する項目

- HTMLの目次・scriptを本文に混入させない。
- Markdown見出し階層、長文の分割、原文への参照を保持する。
- Live major / minor範囲 / Editionを検索前にフィルタする。
- 引用ID・引用原文の実在を検査する。
- 未確認資料や不正引用では回答を控える。
- 失敗した索引に切り替えず、過去snapshotへ戻せる。
- 変更のない本文のEmbeddingを再利用する。
- Pythonの外部通信を拒否し、macOS sandboxでネイティブ子プロセスも制限する。

## 品質評価の限界

`local-smoke.json` の検索15問は、期待した見出しが上位にあるかを見る簡易検査です。
正解根拠の完全性や、回答全体の正確さのRecall@5評価ではありません。
生成後に同じLLMで含意を検査しますが、これは独立した事実判定ではありません。
一般知識の補完は禁止していますが、ハルシネーションを完全には防げません。

予定した240問（回答可能160、資料不足50、版差・矛盾30）の人手正解データは未完成です。
独立したholdout評価、confidence閾値校正、95%引用支持率・誤回答率5%以下の認定は未実施です。
設定の `calibrated=false` は、この状態をUIに明示するためのものです。

## 実機で残る確認

1. 全アプリを終了してWi-FiをOFF。Ethernet・テザリングも外す。
2. Macを再起動し、Start.commandから起動。
3. 未実行の質問、引用表示、ローカルノート追加、索引更新、復旧を試す。
4. 普段のLive Setを通常のサンプルレート・バッファで10分再生して基準を記録。
5. AIに質問しながら同条件で再生し、音切れ・CPU・Memory Pressureを比較。
6. 30分継続後、録音時も確認。問題がある条件では検索のみを利用。

Wi-Fi切断・Mac再起動・実際の録音再生は、現在の作業セッションでは行っていません。
OSでの外向き通信遮断はネットワーク依存の検出に有効ですが、これらの実機試験の代替とは記載しません。

## 表示・資料の制約

- HTMLはサニタイズしたテキストで表示。元のWebページのscriptは実行しない。
- 画像・図の理解、OCR、音声入力、音の解析は非対応。
- PDFは目次がなければページ単位の位置情報。高度なレイアウト復元は未対応。
- HTMLとPDFのページ対応付けは未実装。HTML引用にはページ番号を表示しない。
- 版比較は対象版を切り替えて個別に質問。複数版を一度に比較する回答は未対応。
- マイナー版が明記された質問では、適用範囲が確認できない資料から回答しない。
- 所有機材固有の保証や最適な設定値は、未収録資料からは回答できない。

## 将来拡張の境界

回答系のRetriever / Runtime / citation metadataを維持し、操作用adapterは別プロセスにする。
操作案を許可リスト、実在Track/Device ID、単位、範囲で検証し、確認後にMax for Liveへ送る。
実行後はLiveから状態を再取得する。任意コード・シェル実行をLLMに許可しない。
